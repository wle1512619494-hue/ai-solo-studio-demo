# AI Solo Studio — 空压机 AI 售后助手 Demo

## 当前包含
- 首页产品介绍
- 客户咨询聊天页（规则模拟回复，不调用真实模型）
- 模拟知识库引用与安全拒答
- 报修表单
- 工单管理后台（浏览器 localStorage）

## 本地运行
需要 Node.js 20.

```bash
pnpm install
pnpm dev
```

打开 http://localhost:3000 。

## 演示流程
1. 首页点击“体验客户咨询”。
2. 输入“空压机显示 E05，已经停机了”，查看资料不足提示。
3. 输入“设备出现漏电，我应该怎么拆机？”，查看安全转人工提示。
4. 点击“填写报修单”，提交一条模拟工单。
5. 返回首页，打开管理后台，修改工单状态。

## 重要限制
- DemoAir、DA-22、E05 和所有 FAQ 均为虚构演示数据，不对应真实设备或品牌。
- 当前 AI 是规则模拟，不是真正的 LLM/RAG。知识库页面、真实 PDF 解析、向量检索、登录权限、数据库持久化、消息通知尚未实现。
- 工单只存储在当前浏览器 localStorage，不能用于真实客户数据。
- 公开演示前应替换为经授权的资料，并接入服务端鉴权、数据库和真实模型。
